## Описание
Этот аддон позволяет создавать векторы и линейные операторы в Blender, применять операторы к векторам с ограничением области действия (сужение на подпространство), а также динамически обновлять преобразования.

## Возможности
- Создание точек и стрелок как векторов
- Создание линейных операторов в виде сфер-сеток
- Применение композиции линейных операторов к векторам
- Ограничение действия операторов
- Динамическое обновление координат при изменении свойств и анимации
- Визуализация инвариантных подпространств

## Установка

                                            !!! Рекомендуется использовать версию Blender 4.4.3 !!!

1. Откройте Blender

2. Перейдите в настройки
В меню выберите:
Edit → Preferences

3. Перейдите на вкладку Extensions (или Add-ons).

4. Установите аддон
Нажмите кнопку Install from Disk или Install в правом верхнем углу окна.
В открывшемся окне выберите ZIP-архив с аддоном.
Нажмите Install Add-on.

5. Активируйте аддон
Найдите аддон (Linear Operators and Vectors) в списке (можно воспользоваться поиском по имени).
Поставьте галочку слева от названия аддона, чтобы включить его.

## Использование
- Добавляйте векторы через меню Add -> Mesh -> Vector
- Добавляйте линейные операторы через Add -> Mesh -> Endomorphism
- В панели свойств (N → Соответсвующая категория) настраивайте параметры операторов и векторов
- Управляйте списком операторов, применяемых к вектору, в панели

## Структура кода
- Сразу хочу отметить, что, синтаксис может быть крайне непривычным, так как у Blender API есть определённые требования к нему. В классах вы не увидите конструкторов, а атрибуты будут задаваться крайне нестандартно. Также редакторы могут "ругаться" на код из-за того, что Blender в некоторых местах требует использовать (или даёт право использовать) то, что, вообще, обычно не допускается делать. Для проверку работоспособности кода лучше всего установить сам аддон.

Вот два основных файла:
    - `vector_object.py` — функции и классы для работы с векторами
    - `linear_operator.py` — функции и классы для работы с линейными операторами
К каждому из этих файлов былы добавлены комментарии, сделанные нейросетью, согласно документации Blender API и соблюдающие общепринятые требования к аддонам Blender.
